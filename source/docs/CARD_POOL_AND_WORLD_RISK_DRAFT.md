# e-Knockmate：追加カード案とストーリー世界破壊率（相談用）

実装前のカード案メモ。ここに記した内容は、既存アプリの戦闘ルールやセーブデータにはまだ反映していない。

## 共通のスキル処理

- 通常スキルはTCG式に扱う。Aは発動時に一度処理し、Pは記載条件を満たした時に発動する。
- 効果に「次の」などの期間指定があれば、その指定された機会までを有効期間とする。
- ℵスキルは通常プレイヤーには表示されず、発動もしない。使用プレイヤーがすでにℵなら表示され、有効になる。
- ℵスキルの対象が相手プレイヤーにも及ぶ条件では、その相手もℵプレイヤーである場合に効果が及ぶ。
- ℵスキルは常識的な期間や対象へ勝手に丸めず、原文を文字通り適用する。解釈上の疑問はカードごとに作者へ返す。

## REG19 ℵ₁「交流祟神、他者利用」ᛚ ᛟ ᛇ ᚱ ᛇ ᛊ

**キー／演算子**：`1, 2, 3, 4, 5, 6, 7, 10, 11, 13` ／ `+, −, ×, xMODy`

**(P) 正直な欺瞞**  
貴方はゲーム開始時にキーと演算子を全て見せても良い。その場合、各対戦相手はその見せたキーと自身のキーから1つを使用済みにして消す。

**(A) ごめんで済むから神察はいらない**  
貴方は「正直な欺瞞」を使用している場合、キーの一つを「嘘だった」として別の発音可能な実数に変えて良い。

作者メモ：ロキ＋エリスのテーマ。

## Revenger18 / R18「圏力鬼神」破釜ウラ

**キー／演算子**：`−1, 1, 2, 3, 5, 7, 11, 17, 19, 139` ／ `+, −, xMODy, i`

**(A) 選考のLONDOH**  
残りのキーが5個の場合、このスキルを使用出来る。相手は「使用エノクメイトをこれと交換する」事を選んでも良い。（使用状況は引き継ぐ）選ばない場合、貴方の次のアタックはガード出来ない。

作者メモ：作者＋温羅のテーマ。添付された[ドラゴン娘の画像](art-references/ura-dragon-inferno-burst.jpeg)をウラのイラスト案として扱う。画像上の見出しは「ドラゴン・インフェル・バースト／龍焔神破撃」。

## RDoC11「自己開封」大流ロス

**キー／演算子**：`9, 7, 4, 2, 1, 1, 2, 4, 5, 9` ／ `+, −, ×, ÷`

**(A) 逆3面鏡の鈍角逆封鎖**  
貴方は「同一数字のキー2つ」と「＋ − × ÷」のいずれかを使用してガードしても良い。そして「カウンターメイト：このスキルによるガード値が16以上」を得る。

作者メモ：ティンダロス＋ダイダロス＋ケルベロス＋タルタロスのテーマ。

## GRAD ∅（圧力否定）「空集合」羅節ゼノン

**キー／演算子**：`0, 1, 2, 3, 4, 6, 8, 9, 10, 12` ／ `+, −, not, ∅`

- `not`：その数字以外をガード出来る。
- `∅`：解なしをガード出来る。

**(P) 存在不能存在証明**  
貴方が`not`でガードした時、宣言する事。各プレイヤーは、キーか演算子を指定し、使用メイトのその範囲から2つを消滅させる。これによりキーが全て消えたプレイヤーは消滅する。

## Graded400「インフレーション」釣果グース

**キー／演算子**：`0, 1, 2, 4, 8, 0, 1, 2, 6, 24` ／ `+, −, ×, ÷`

**(A) サイドステップ**  
キーを一つ選ぶ、あなたはその「2倍」か「半分」でガードかアタックする。

**(P) 勝者は二人！**  
このメイトがアピアメイトした時、敗北しなかったメイトを1つ選び、互いに勝利とする。

## E=mu²「神隠し」海流波（ミルハ）—画像先行カード案

添付の青系カード画像は、この追加メイトのビジュアル案として扱う。カード画像に記載された表記を転記した。カード画像：[`miruha-137-year-problem.png`](art-references/miruha-137-year-problem.png)

**キー／演算子**：`1, 2, 4, 6, 8, 10, 12, 20, 66, 100` ／ `+, −, ×, ÷`

**(A) 運のない世界**  
メイト1つを選ぶ。あなたはD4、D6、D8、D12、D20を振る。その相手の残りキーは、その出目になる。

**ℵ₆(P) 137年間問題「歴史の先端」**（ℵプレイヤー相手時有効）  
いずれかの条件を満たしたら全員敗北する。

- 誰が宣言したかに関係なく、キーの宣言が1、3、7の順番で登場する。
- 137のキーが使用される。

作者メモ：珍しく穏当な印象のℵ効果だが、結果は「全員敗北」。勝者を作らず、対局参加者全員が敗北する扱い。

## R=DEG17「量子探偵」久遠他無 — 画像先行カード案

添付カード画像：[quantum-detective-kuon-tamu.png](art-references/quantum-detective-kuon-tamu.png)

**画像に記載されたキー**：`2, 3, 4, 5, 6, 7, 1, 6, 8, 10, 12` ／ **演算子**：`+, −, ×, ÷`

このカードだけキーを11個持つ。通常カードと同じ10キーへ削らない。

**インターフェース／データ設計メモ**

- 通常カードの画面配置は変更しない。このカードの11個目のキーだけ、カード固有の追加枠に表示する。
- 10キー＋4演算子の14枠をカードデータ全体の固定上限にしない。今後、合計16枠などのカードが必要になる可能性を考え、カードごとのキー数・演算子数から表示枠を構成できる形にする。
- 16枠を現時点の確定上限とはしない。通常カードの見た目を変えず、追加資源のあるカードだけ必要な枠を表示する。

**(A) 量子攻撃**  
あなたはキーを2つ選び、「どちらかでアタック」と宣言してよい。相手のガード宣言を確認した後、そのガードに対して都合のよい方のキーでアタックした、という事実を選択する。ただし、選択したアタックが不可能であった場合、そのアタックは「スルー」として扱い、選択した2つのキーを消費する。

**(P) 重なる世界**  
複数の可能性がある攻撃が同時にガードされ、どちらも成立してしまった時、あなたはラベル「ℵ: InfinityZero」を得る。このラベルは、このラベルの存在確率が0%になるまで保持する。

処理上は、Aを「2つのキーを候補として保留し、相手のガード宣言後に攻撃分岐を選ぶ」手順として扱う。最初から2回攻撃する効果ではない。Pは単なる複数候補の発生ではなく、複数の可能性が同時にガードされ、双方のガードが成立した時に限る。

### このカードの実装前に決める点

- 「同時にガード」の際、相手に複数のガード宣言を要求するのか、1つのガードが複数分岐を同時に成立させ得るのか。
- Aでいう「選択したアタックが不可能」の判定時点と、スルー処理後の手番。
- ℵ:InfinityZeroの「存在確率」がどのプレイヤー／世界の値を指すか、また0%判定がどのイベントで再評価されるか。
- このラベルはプレイヤー主体に保存する。通常の対局終了やリセットで解除する処理は追加しない。

## ストーリーの世界破壊率：初期提案

**提案値：非DEG17のストーリー対戦で敗北するたび、世界破壊率を5ポイント上げる。**

- 初期値は0%。同一ストーリー世界の共有値として保存する。
- 非DEG17相手への勝利では上昇しない。敗北しても、率が100%に届くまではキャラクターは死亡しない。
- 100%に達した時点で世界が破壊され、ストーリー上の主人公は死亡する。例えば0%からなら、非DEG17戦で20回敗北すると100%に達する。
- DEG17の敗北時処理は既存設定のまま。この加算ルールへ混ぜない。
- 練習戦では変化しない。

5ポイントは、敗北に意味を持たせつつ、初期設定で即座に死へ近づけないための暫定値。数値は後で調整できる。

### 保留点

- 世界破壊率が100%になった後の再挑戦、新しいストーリー世界での初期値。
- 多人数ストーリー戦で、誰か一人の敗北を共有値に加算するか、全員敗北の時だけ加算するか。
- `xMODy`と`i`の演算・宣言手順。
- 「残りのキーが5個」の参照タイミング、他カードへの交換後にどの状態を引き継ぐか。
- 「キーか演算子を指定し、2つを消滅」の各プレイヤーにおける選択手順。
- 「カウンターメイト」「サイドステップ」「アピアメイト時」の厳密な処理窓。

これらは現時点では勝手に補完せず、対戦実装の前に確定する。
