e-Knockmate v0.25 TEST
======================

Run locally
-----------
Unzip this folder and open index.html in a modern browser. The game is a static app; saves are stored in that browser's localStorage. Use the same browser profile to keep the save.

What is in this test build
--------------------------
- Current story demo and battle flow, with a versioned test copy of the app.
- Additional card prototypes: REG19, Revenger18 Ura, RDoC11, GRAD empty set, Graded400, Miruha, and the 11-key Quantum Detective.
- The Quantum Detective uses a card-specific 8-column layout for six keys and two operators per row. Other cards keep their ordinary layout.
- Non-DEG17 story losses raise the local world destruction meter by 5 percentage points; at 100%, the story world is marked destroyed.
- Card reference art and the current rule / prototype notes are included in source/docs.

Prototype status
----------------
This is a test build, not a release candidate. Several newly introduced card effects are operational prototypes based on the current draft, and some choices or edge cases still need author review. In particular, the Ura exchange choice and some multi-player / timeline wording are not final. The build does not claim to fully implement every future Aleph interpretation.

There is no developer reset page in this package. Browser save data is separate from files in the ZIP.
